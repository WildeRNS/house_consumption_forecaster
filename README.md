# House Consumption Forecaster for Home Assistant

Кастомна інтеграція для Home Assistant, призначена для прогнозування добового споживання електроенергії будинком. Інтеграція аналізує історичні дані за останні 7 днів, враховує сонячні прогнози, температуру повітря та робочі/вихідні дні.

## 🚀 Можливості
- Автоматичний розрахунок прогнозу споживання електроенергії на сьогодні та завтра.
- Врахування даних сонячної генерації (Volcast / Solcast).
- Інтеграція через зручний графічний інтерфейс (Config Flow & Options Flow) без необхідності редагувати YAML.
- Динамічне оновлення даних та підтримка сенсорів енергії.

## 📦 Встановлення (через HACS)

1. Відкрийте **HACS** у вашому Home Assistant.
2. Перейдіть у розділ **Інтеграції** (Integrations).
3. Натисніть на три крапки у правому верхньому кутку та виберіть **Користувацькі репозиторії** (Custom repositories).
4. Вставте URL вашого GitHub-репозиторію та оберіть категорію **Integration**.
5. Натисніть **Додати**, після чого знайдіть `House Consumption Forecaster` у списку та натисніть **Встановити**.
6. Перезапустіть Home Assistant.

## ⚙️ Налаштування

1. Перейдіть в **Налаштування** $\rightarrow$ **Пристрої та служби** (Devices & Services).
2. Натисніть **Додати інтеграцію** (Add Integration) та знайдіть **House Consumption Forecaster**.
3. Виберіть необхідні сенсори для підрахунку:
   - Сенсор споживання будинку
   - Сенсор фактичної генерації СЕС
   - Прогноз генерації на сьогодні та завтра
   - Сенсор температури
   - Сенсор робочих днів (binary_sensor)

## 📊 Використання
Після налаштування інтеграція створить основні сенсори прогнозу:
- `sensor.house_energy_forecast_today` (Прогноз на сьогодні)
- `sensor.house_energy_forecast_tomorrow` (Прогноз на завтра)
